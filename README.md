**Beyond The Score** is an AI-powered football studio where 5 virtual hosts collaborate in real time to transform match events into explainable insights, tactical analysis, personalised commentary, and automated match narratives.

## Meet Your Hosts

### Jimmy
**The Host & Orchestrator**

Jimmy keeps the show moving, highlights key moments, introduces breaking developments, and guides viewers through the evolving story of the match.

### Statto Sam
**The Analyst**

Sam transforms raw match events into meaningful football intelligence, uncovering trends in possession, pass quality, player performance, pressure metrics, and overall team effectiveness.

### Macca
**The Tactician**

Macca explains the game behind the statistics, focusing on formations, pressing structures, attacking patterns, tactical adjustments, and the battle for control.


### Sophie
**The Storyteller**

Sophie uncovers the narratives emerging throughout the match and answers the most important question for viewers: **Why does this moment matter?**


### Rico
**The Broadcaster**

Rico personalises every insight for different audiences, adapting the same intelligence for the selected audience tone.

## How It Works

Beyond The Match follows an end-to-end intelligence pipeline:

1. **Ingest** live synthetic football events as they happen.
2. **Interpret** events into meaningful football intelligence and match states.
3. **Explain** why moments matter through contextual AI reasoning.
4. **Render** insights as a studio-themed UI which users can interact with.
5. **Personalise** the experience based on audience type. There are 3 modes to choose from: Matchday fan, Season ticket fan or Statto!

## Key Features

- Real-time match intelligence and event processing
- Tactical and statistical match analysis
- Explainable football storytelling
- Matchday, Season ticket, and Statto fan experiences
- Automated recaps
- Personalised viewing experience for every fan

## Technology

Built using Microsoft Azure, Azure AI Foundry, Semantic Kernel, .NET, Blazor, SignalR, Azure SQL, and deployed using .NET Aspire, Beyond The Match demonstrates how multi-agent AI systems can collaborate to transform football events into explainable match intelligence, compelling stories, and personalised fan experiences.
